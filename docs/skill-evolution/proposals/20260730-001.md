# Proposal: Add Instagram Reel DASH Format Workaround to youtube-downloader

## 1. What is wrong today

The `youtube-downloader` skill recommends the standard `bestvideo[height<=1080]+bestaudio/best[height<=1080]` format selector for all downloads, including Instagram. **Instagram Reels deliver video and audio as separate DASH streams with custom format IDs (e.g., `dash-1342288424472151v`), and the standard selector fails with `Requested format is not available. Use --list-formats for a list of available formats`.** The skill has no documented workaround for this, so every agent must discover the `--list-formats` → manual format ID selection workflow from scratch.

## 2. Evidence

Session `20260729_132655_7124376d` ("Descargar video de Instagram", Telegram, 20 messages, 2 user messages):

**The agent followed the skill's instructions exactly and hit the wall:**

1. Inspected the video (message 29058: `yt-dlp --print title ...` → succeeded)
2. Ran the standard format selector from the skill (message 29063: `-f "bestvideo[height<=1080]+bestaudio/best[height<=1080]"`) → **failed** with `Requested format is not available. Use --list-formats for a list of available formats`
3. Had to manually discover the workaround: `--list-formats` (message 29065) revealed DASH format IDs like `dash-1342288424472151v` (video) and `dash-1597072301350816a` (audio)
4. Combined them manually: `-f "dash-1342288424472151v+dash-1597072301350816a"` → succeeded (message 29067)
5. User asked afterwards (message 29376): "por qué ha fallado?" — indicating the failure was confusing even after it was resolved

**The skill's Instagram section only documents:**
- Public posts: `yt-dlp -o "..." "URL"` (line 96) — no format selector
- Carousel posts: same pattern (line 108)
- Rate-limited: `--cookies-from-browser` (line 99)

**None of these help when the format selector itself is the problem.** The DASH format ID issue is Instagram-specific and affects every yt-dlp download from Instagram Reels.

### Proposed text

Replace the Instagram single post section with:

```markdown
### Instagram single post

Instagram delivers video and audio as **separate DASH streams** with custom IDs (e.g., `dash-1342288424472151v`). The standard `bestvideo+bestaudio` selector may fail with:

```
ERROR: Requested format is not available. Use --list-formats for a list of available formats
```

**Recommended workflow:**

1. **List available formats first** to find the DASH format IDs:
   ```bash
   yt-dlp --list-formats "https://www.instagram.com/p/CODE/"
   ```
   Look for the best video-only format (e.g., `dash-XXXXv` at 1080p) and the audio-only format (e.g., `dash-XXXXa`).

2. **Download with explicit format IDs** (merge video + audio):
   ```bash
   yt-dlp -f "dash-VIDEO_ID+dash-AUDIO_ID" --merge-output-format mp4 \
     -o "~/Downloads/%(title)s.%(ext)s" "https://www.instagram.com/p/CODE/"
   ```
   Replace `VIDEO_ID` and `AUDIO_ID` with the actual IDs from step 1. Use `--merge-output-format mp4` for better compatibility.

3. **Quick one-liner** (1080p most common format — run `--list-formats` to verify IDs):
   ```bash
   yt-dlp -f "dash-VIDEO_ID+dash-AUDIO_ID" --merge-output-format mp4 \
     -o "~/Downloads/%(title)s.%(ext)s" "https://www.instagram.com/reel/CODE/"
   ```

**Authentication (when rate-limited):**
```bash
yt-dlp --cookies-from-browser safari -o "~/Downloads/%(title)s.%(ext)s" "https://www.instagram.com/p/CODE/"
```
```

## 4. What improves, and how you would know

**Behavioral change:** When an agent encounters an Instagram video download with the format error, it will:
1. Recognize the DASH format ID pattern immediately
2. Run `--list-formats` first (instead of guessing format selectors)
3. Use the explicit `dash-XXXXv+dash-XXXXa` format string
4. Not lose a tool call discovering the workaround

**Verification check:** Ask the agent to "download this Instagram Reel: https://www.instagram.com/reel/DYC0GzQRGH0/" — the agent should run `--list-formats` before the download command, and the format string should use explicit DASH IDs, not the generic selector. If the agent tries `-f "bestvideo+bestaudio"` directly against an Instagram URL, this proposal hasn't been applied effectively.

## 5. Trade-offs and risks

- **Format IDs change per video** — `dash-XXXXv` IDs are video-specific, so the skill can only document the workflow, not provide a one-size-fits-all command. This is unavoidable and is already what the agent had to discover.
- **More verbose Instagram section** — adding 15-20 lines to an already sizable Instagram section. The added prose is procedural rather than reference, but the DASH ID issue is the most common Instagram failure and justifies the space.
- **Threads uses the same DASH pattern** — but Threads is currently downloaded via Playwright (downloader site), not yt-dlp. If Threads becomes yt-dlp-compatible in the future, this same workaround would apply. Not a risk, just a note.
- **Not user-facing** — Carlo almost certainly won't read this section. The improvement is entirely agent-side: the agent will make fewer mistakes and need fewer turns when downloading Instagram videos.
